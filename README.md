# Nyansatek Studio

A print-shop design studio in one HTML file: mugs, T-shirts, caps, plates, flyers, business cards, certificates and stickers, designed at 300 DPI.

**Open it:** https://webstar-7.github.io/studio/

- Text, shapes, photos, crop, eraser, knife, layers, groups, undo
- Open a PDF or a scanned page and edit its text (OCR for scans)
- Emboss, letterpress, 3D block, gold and silver foil, neon text styles
- Find & replace across a design
- AI Design with your own Anthropic API key
- Export PNG, JPG or PDF, with sheet layouts, cut marks and mirror printing
- Designs save in the browser under My Designs; back them up from there
